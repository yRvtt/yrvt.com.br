## ⚡ Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio web. Ele não é apenas um site estático, mas sim uma interface que demonstra minhas habilidades em criar experiências de usuário ricas, interativas e extremamente performáticas.

### 🌟 Destaques:
- **Design Cyberpunk/Glassmorphism:** Interface fluida, moderna e que impressiona no primeiro olhar.
- **Formulário de Contato Dinâmico:** Integrado diretamente com a minha API própria (`email.yrvt.com.br/api`) com sistema de honeypot, validação de requisições e rate-limiting (Anti-Spam).
- **Altamente Otimizado:** SEO técnico impecável, OpenGraph configurado, carregamento assíncrono e zero dependências pesadas no front-end.
- **Responsividade Pura:** Layout adaptativo para todas as telas (Mobile First to Ultra-wide).

## 🚀 Como visualizar localmente

Este é um projeto que não exige frameworks ou processos de build complexos para rodar a interface visual.

1. Clone o repositório:
   ```bash
   git clone https://github.com/yRvtt/yrvt.com.br.git
   ```
2. Navegue até o diretório:
   ```bash
   cd yrvt.com.br
   ```
3. Abra o arquivo `index.html` em seu navegador ou inicie um Live Server.
   ```bash
   npx serve .
   ```

> **Nota:** A funcionalidade de envio de email via formulário de contato realiza uma requisição para uma API em produção. Requisições em `localhost` podem ser bloqueadas pelas regras de CORS configuradas na VPS por razões de segurança.
